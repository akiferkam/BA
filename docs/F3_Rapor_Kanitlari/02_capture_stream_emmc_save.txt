== ADIM 3: KALICILIK DOGRULAMASI (sync + umount + remount) ==
$ sync; sudo umount /mnt/emmc && echo UMOUNT_OK; sudo mount /dev/mmcblk0 /mnt/emmc && echo REMOUNT_OK; ls -la /mnt/emmc/demo_stream.raw

YORUM:
Dosya, unmount+remount sonrasi TAMAMEN AYNI boyutta (240408 byte)
hala orada - bu, verinin gercekten flash'a yazildigini (sadece
page cache'te tutulmadigini) kaniti1yor. F3'un "Capture + Stream +
EMMC Save" demo hedefi uctan uca dogrulanmis oldu.
